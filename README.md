# PhotoJoy

**공개 웹 버전 0.5:** [PhotoJoy 열기](https://qufl4252-collab.github.io/PhotoJoy/) · [웹 사용·개발·데이터 이전 안내](PAGES_README.md). 이메일/Google 로그인 후 사진을 추가하고 자동 분류를 시작하면 아이별 정리까지 수행합니다. 불확실한 얼굴만 확인 필요로 남습니다. 사진은 현재 브라우저 안에 보관됩니다.

기존 자체 호스팅 웹 0.3은 `PhotoJoy-Web.cmd`로 실행하는 별도 서버 버전입니다. [서버 실행 안내](WEB_README.md)는 해당 버전에 적용됩니다. 기존 데이터는 보존되며 새 웹으로 옮기는 절차는 위 안내를 확인하세요.

**Windows 버전 0.2.0:** 아래는 기존 데스크톱 프로그램 설명입니다.

아이별 사진 정리를 위한 Windows 프로그램입니다. 왼쪽 단계 메뉴, 사진 카드 목록, 얼굴별 미리보기와 사용 가이드를 제공합니다.

## 실행

`PhotoJoy.cmd`를 더블클릭하거나 `dist-0.2/PhotoJoy/PhotoJoy.exe`를 실행합니다. 실행 파일을 다른 PC로 옮길 때는 `dist-0.2/PhotoJoy` 폴더 전체를 복사합니다. 모델과 DLL이 포함된 `_internal` 폴더가 필요합니다. 이전 버전의 `dist` 폴더는 보존되어 있습니다.

오른쪽 위 버튼은 **톱니 가이드 → 최소화 → 전체화면/창모드 → 닫기** 순서입니다. 전체화면/창모드 버튼은 작업 표시줄을 유지하는 최대화/복원을 수행합니다. 제목 영역을 끌어 창을 옮기고, 오른쪽 아래 모서리로 창 크기를 바꿀 수 있습니다.

## 한글 이름 입력과 가이드

- 아이 관리의 `아이 추가`와 `이름·그룹 수정`에서 한글 이름을 입력합니다. 아이 행을 더블클릭해도 수정할 수 있습니다.
- 이름 입력창은 설치된 한국어 입력기를 활성화합니다. Windows 입력기에 접근할 수 없는 실행 환경에서는 한글 직접 입력으로 전환합니다.
- 영문만 나온다면 **한글 입력 켜기**를 누르세요. `한글 직접 입력 (두벌식)`이 켜지면 두벌식 자판으로 한글을 조합합니다. 이름·그룹 칸에만 적용되며 다른 앱의 키보드 설정은 변경하지 않습니다.
- 영문 이름을 입력하려면 `한글 직접 입력 (두벌식)` 체크를 해제합니다. 일반 모드에서는 Windows 입력기의 한/영 상태를 따릅니다. 복사·붙여넣기도 사용할 수 있습니다.
- Enter는 이름을 바로 저장하지 않습니다. 입력을 마친 뒤 `저장` 버튼을 누릅니다.
- 상단 **톱니 가이드** 또는 **F1**을 누르면 단계별 사용 방법을 볼 수 있습니다. 가이드의 `이 화면으로 이동`으로 해당 기능을 열 수 있습니다.

## 사용 순서

1. **작업 폴더 선택**: 정리본과 PhotoJoy 데이터가 저장될 폴더를 고릅니다.
2. **아이 관리**: 아이를 추가하고 선택한 뒤 참고 사진을 등록합니다. 얼굴이 여러 개면 해당 아이의 얼굴을 직접 고릅니다. 이름이 같아도 고유 ID로 구분합니다.
3. **사진 분류**: `사진·영상 추가` 또는 `폴더 분석`을 누릅니다. 실제 YuNet·SFace 모델이 얼굴을 찾아 등록 특징과 비교합니다. HEIC 사진도 읽을 수 있습니다.
4. **결과 검토·교정**: 사진 카드를 고르면 오른쪽에 미리보기와 얼굴 후보가 나타납니다. 후보가 맞으면 `후보대로 확인`, 다르거나 보류이면 `직접 배정`으로 등장 아이들을 선택합니다. 여러 자료는 Ctrl+클릭, 연속 선택은 Shift+클릭입니다. 상태 필터·파일명/아이 이름 검색·촬영일 정렬·목록 보기로 자료를 찾을 수 있습니다. 필터로 숨겨진 자료는 선택에서도 빠집니다.
5. **참고 얼굴 추가**: 얼굴 목록에서 하나를 선택하고 인식 결과 옆 `··· → 선택 얼굴을 참고 얼굴로 등록`을 누릅니다. 여러 얼굴을 한 사람으로 무조건 학습하지 않습니다. 상단 `다시 비교`로 미확정 후보에 반영합니다.
6. **정리 계획**: 일별·주차별을 선택하고 `정리 계획 확인·실행`을 누릅니다. 선택 자료가 있으면 그 자료, 선택이 없으면 확인 완료된 전체 자료가 대상입니다. 계획을 확인하면 원본을 보존하며 복사합니다.
7. **보내기 준비·통계**: 기간과 아이를 선택해 ZIP 또는 CSV를 만듭니다. PNG 로고를 골라 내보내는 사진에만 워터마크를 넣을 수 있습니다. 통계의 월별 그래프는 확인된 자료를 집계합니다.
8. **작업 이력·설정**: 실패·중단된 정리를 재시도하고 완료된 복사본을 되돌릴 수 있습니다. 원본이 없거나 정리본이 변경된 경우 파일을 보존합니다. `인식 설정·모델 진단`에서 비교 기준을 조정할 수 있습니다.

ZIP 생성은 발송이 아닙니다. 실제로 카카오톡·알림장에 보낸 뒤 `직접 보냈음 확인`으로 기록합니다.

## 저장 구조

작업 폴더의 `.photojoy`에는 SQLite DB·참고 얼굴·미리보기가 저장됩니다. `정리`, `전송묶음`, `백업`에는 결과가 저장됩니다. 원본 파일은 읽고 복사하며 삭제하거나 덮어쓰지 않습니다. 정리·ZIP 전에 분석 때의 파일 해시를 확인합니다.

아이 이름 변경은 이미 정리된 폴더를 자동으로 이동하지 않습니다. 재정리 시 기존에 성공한 같은 아이·미디어 조합을 건너뜁니다. 그룹은 현재 메모용이며 형제별 ZIP은 따로 생성합니다.

## 인식 기준과 한계

- CPU에서 YuNet 얼굴 검출 + SFace 특징 추출을 수행합니다. 외부 API 키나 로그인은 필요 없습니다.
- 기본 비교 유사도 0.50, 차순위 간격 0.08은 **PhotoJoy의 실험적 초기값**입니다. 등록 후보가 한 명이면 추가로 0.08을 요구합니다. 실제 어린이 자료로 보정된 정확도 수치가 아닙니다.
- 모든 파일은 사람이 확인·배정한 후에 정리합니다. 자동 후보는 확정 상태가 아닙니다.
- 영상은 최대 8개 프레임만 분석하므로 짧게 등장한 인물을 놓칠 수 있습니다.
- 실제 얼굴 샘플 시험은 공개 성인 사진 2장과 파생 이미지·영상으로 기능 연결을 검증한 것입니다. 형제·성장·가림·각도 변화 등 현장 정확도는 미검증입니다.
- 사진 날짜는 EXIF → 유효한 파일명 날짜 → 수정 시각 순서입니다. 영상 컨테이너의 촬영일 메타데이터는 아직 읽지 않으므로 표시된 날짜를 확인하세요.
- 일반적인 이미지·영상 읽기를 지원하지만 모든 카메라 코덱·HEIC 변형·HDR 색을 검증하지 않았습니다.
- MOV→MP4 변환, 하이라이트 영상, 자동 폴더 감시, 백업 복원 UI는 이번 0.1 범위에 포함되지 않습니다.
- InsightFace 어댑터 소스는 준비되어 있으나 기본 배포·UI에는 포함하지 않았고 별도 실모델 검증도 하지 않았습니다.

## 개발 실행

Python 3.12 x64에서 아래 순서로 준비합니다.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe scripts\prepare_models.py
.\.venv\Scripts\python.exe run_photojoy.py
```

`prepare_models.py`는 공식 모델 두 개를 내려받고 공개 Git LFS SHA-256 및 크기를 비교합니다. 정상 모델이 있으면 재다운로드하지 않습니다. 앱 자체는 모델을 자동 다운로드하지 않습니다.

```powershell
.\.venv\Scripts\python.exe -m pytest -q --basetemp=test-output/pytest
.\.venv\Scripts\python.exe scripts\collect_licenses.py
.\.venv\Scripts\python.exe -m PyInstaller --noconfirm --distpath dist-0.2 PhotoJoy.spec
```

`--basetemp`는 테스트 전용 경로만 지정하세요. pytest가 해당 경로를 정리할 수 있습니다.
